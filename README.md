# BillBuddy: SaaS Startup Financial Model

A three-statement financial model for a **fictional** software startup,
built in Excel as part of my journey into startup financial modeling.

BillBuddy sells invoicing software to small businesses for $40 a month.
All numbers are made up for practice. This is not financial advice.

## What it does
- Forecasts 24 months of customers, revenue and gross profit
- Models churn, new customers, hosting costs and fixed costs
- Builds an income statement, cash flow statement and balance sheet
- Includes check rows that show 0 when the statements balance

## Tabs
| Tab | Purpose |
|---|---|
| Setup | Opening balance sheet |
| Assumptions | All inputs in one place |
| Revenue | Customer and revenue schedule |
| IS | Income statement |
| CF | Cash flow statement |
| BS | Balance sheet with check row |
| Summary | Key numbers for months 1, 6, 12 and 24 |

## Key assumptions (fictional)
- Starting customers: 60
- New customers per month: 15
- Monthly churn: 4%
- Price: $40 per customer per month
- Hosting and support: $6 per customer per month
- Fixed costs: $11,000 per month (salaries, marketing, software)
- Seed funding: $150,000 cash

## Key results (24 months)
- Revenue: about $171,000
- Net loss: about $127,000
- Closing cash: about $31,000
- Break-even needs roughly 324 customers (fixed costs divided by $34 profit per customer)
- On these assumptions, break-even falls well beyond the 24-month forecast

## How to use
Open the Excel file and change the blue cells on the Assumptions tab.
Everything else updates automatically. Check rows should always show 0.
